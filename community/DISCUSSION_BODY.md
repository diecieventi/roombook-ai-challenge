# Condividi la tua RoomBook Challenge

Hai completato la challenge e vuoi condividere il risultato?

Lascia **un commento in questa unica Discussion** con il link alla tua repository pubblica.

Non esiste una classifica e nessuno certifica o assegna un punteggio alle repository condivise.

Lo scopo è semplicemente rendere disponibili esempi reali a chi vuole vedere come altre persone hanno affrontato la challenge.

La tua repository può contenere, per esempio:

- specifica e implementation plan;
- codice sorgente;
- note di review;
- `ROOMBOOK_EVALUATION.md`;
- `ROOMBOOK_EVALUATION.json`;
- `CHALLENGE_RETROSPECTIVE.md`.

Se vuoi, aggiungi anche una frase su qualcosa che hai imparato o che ti ha sorpreso.

Esempio:

```text
https://github.com/username/roombook-challenge

Non avevo considerato la race condition prima della fase di review.
```

Se non vuoi condividere nulla pubblicamente, non devi fare niente. La challenge è comunque conclusa.
